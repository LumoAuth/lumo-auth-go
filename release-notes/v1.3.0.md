## Highlights & New Features

### 1. Private Key JWT (`private_key_jwt`) Agent Authentication (`github.com/lumoauth/lumo-auth-go`)

Agents registered with the **Private key JWT** identity type can now authenticate without a client secret by signing short-lived RFC 7523 JWT client assertions (`urn:ietf:params:oauth:client-assertion-type:jwt-bearer`, `typ: client-authentication+jwt`).

- Added `ClientAssertionSigner`, `ClientAssertionOptions`, `IssuerFor`, and constants (`ClientAssertionType`, `ClientAssertionTyp`, `MaxClientAssertionLifetime`, `EnvAgentPrivateKey`, `EnvAgentKeyID`) in `client_assertion.go` with support for `ES256`, `ES384`, `ES512`, `EdDSA` (Ed25519), `RS256`–`RS512`, and `PS256`–`PS512` (RSA ≥ 2048 bits):
  - `GenerateClientAssertionSigner(algorithm, keyID)` to generate key pairs and export `PublicJWK()`, `JWKS()`, and `PrivateKeyPEM()`.
  - `LoadClientAssertionSigner(pemData, opts)` to parse PEM private keys (PKCS#8, SEC 1, or PKCS#1) and `NewClientAssertionSigner(key, opts)` to wrap a `crypto.Signer`.
  - Single-use assertion generation via `signer.Assertion(clientID, audience)` with random `jti` and configurable lifetime (default `60s`, max `10m`).
- Extended `Agent` and `AgentConfig` (`agent.go`) with:
  - `PrivateKey` field (accepts a `*ClientAssertionSigner`; defaults to loading the PEM key in `AGENT_PRIVATE_KEY` with `KeyID` from `AGENT_KEY_ID`).
  - `Issuer` field for custom domains (defaults to `IssuerFor(BaseURL, OrgID)`).
  - `agent.ClientAssertion()` to sign single-use assertions on demand.
  - Strict validation ensuring `ClientSecret` and `PrivateKey` are mutually exclusive.
- Added `AuthResource.ClientCredentialsWithAssertion(ctx, clientID, clientAssertion, scopes...)` (`resource_auth.go`) to perform the client-credentials grant with a signed assertion on a standalone `Client`.

```go
package main

import (
	"context"
	"os"

	lumoauth "github.com/lumoauth/lumo-auth-go"
)

func main() {
	signer, err := lumoauth.LoadClientAssertionSigner(os.Getenv("AGENT_PRIVATE_KEY"),
		lumoauth.ClientAssertionOptions{KeyID: "agent-2026-11"})
	if err != nil {
		panic(err)
	}

	agent, err := lumoauth.NewAgent(lumoauth.AgentConfig{
		ClientID:   "agt_0123456789abcdef",
		PrivateKey: signer,
	})
	if err != nil {
		panic(err)
	}

	_, err = agent.Authenticate(context.Background())
	if err != nil {
		panic(err)
	}
}
```
